Sketch before you specify
Candidates
Every new idea lands here first. Leave Foundations alone until a candidate is adopted. Duplicate candidates/_template.html, sketch in HTML, and this page picks it up on reload. Production never receives this markup — only a design.md diff after adoption.
Entry points
mobbin
Component redesign
Mobbin URL for one component. Steal structure and interaction, restyle with Vanyshr tokens.
screenshot
Component converter
Screenshot of a single control or card. Extract pattern and states, not colors or type.
layout
Page layout converter
Full-page screenshot. Inventory components, reuse adopted ones, assemble a candidate layout.
interaction
Interaction pattern
Video, GIF, or description. Prototype trigger, transition, and end state in working HTML.
token
System extension
New color, spacing, type, or radius. Propose in design.md and demo it here first.
refinement
Small tweak
Padding, border, size. Change one property. Skip this page only if the adopted version is already correct and the tweak is tiny.
